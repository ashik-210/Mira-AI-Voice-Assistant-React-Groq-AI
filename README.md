# 🎙️ Mira – AI Voice Assistant

**Mira – Socially Awkward, Digitally Smart** is an AI-powered voice assistant built with React, Groq AI, and the Web Speech API. It can understand voice commands, answer questions, speak responses, open websites, tell the current date and time, and provide current weather information.

## 🌐 Live Demo

🚀 **[Try Mira Live](https://mira-the-ai.netlify.app/)**

💻 **[Mira – AI Voice Assistant](https://github.com/ashik-210/Mira-AI-Voice-Assistant-React-Groq-AI)**

## ✨ Features

- 🤖 **AI-Powered Responses** – Ask questions and get intelligent responses using Groq AI.
- 🎤 **Voice Recognition** – Interact with Mira using your voice.
- 🔊 **Text-to-Speech** – Mira speaks her responses aloud.
- 🌐 **Open Websites** – Open websites using voice commands.
- 📅 **Date Information** – Ask Mira for today's date.
- ⏰ **Time Information** – Get the current time.
- 🌤️ **Weather Information** – Check current weather for different cities and countries.
- 🎨 **Interactive UI** – A simple and responsive user interface.

## 🚀 Getting Started

Follow these steps to run Mira locally.

### 1. Clone the repository

```bash
git clone https://github.com/ashik-210/Mira-AI-Voice-Assistant-React-Groq-AI.git
```

### 2. Open the project folder

```bash
cd Mira-AI-Voice-Assistant-React-Groq-AI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure the Groq API

Mira uses the Groq API to generate AI responses.

Configure your API integration before running the project. Keep your API key private. Do not commit API keys or other secrets to GitHub.

**Important:** A key used directly in frontend code can be viewed by visitors. For a secure deployment, route API requests through a backend that stores the key in an environment variable.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
